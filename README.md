## 小满帮你记什么

- **挑重点记录**：手动开启收音后，筛选人声、转成文字，再按你设置的关注领域提取有用信息，过滤无信息量的闲聊和重复内容。
- **有用的时间轴**：按时间回看做了什么、聊了什么，最新内容在前，可折叠查看。
- **重点合并**：围绕同一件事归纳多段记录，分清背景、进展、结论和后续关注，不用翻一堆零散转写。
- **待办由你确认**：从整理后的重点中提出候选事项。确认后才成为你的待办，不把别人的任务直接算到你头上。
- **AI 日记 → 日历**：默认每晚 **21:00** 根据当天已经整理的内容写日记；授权系统日历且有可写日历后，自动写入当天日程，方便长期回顾。后台调度可能延后。
- **随时问小满**：在搜索框查人物、事情、项目或日期，也能直接提问，从已有记录里找答案并查看来源。
- **按自己的习惯用**：关注重点、身份背景、日记风格和篇幅、待办提醒、定时停止录音都能调整。

## 三步开始

1. **安装 APK**：支持 Android 13 及以上、ARM64 手机。公开体验版与开发者私人版分开安装，不含任何人的历史记录。
2. **点右上角齿轮**：在「关注重点与使用习惯」填写自己的身份和关注领域；在「云端 API」选择平台，填写自己的 Key，测试连接后保存。默认均不含私人配置。
3. **点开始记录**：允许麦克风和通知权限；需要日记进入日历时，在设置中点「AI 日记加入日历」授权。录音由你开启，也可以随时暂停。

## API 自己选

内置 **阿里云百炼、DeepSeek、硅基流动、OpenAI** 四个平台预设，自动填写地址与参考模型，也可修改模型名称。其他平台可通过 **自定义 OpenAI 兼容接口**填写 HTTPS 地址、模型和 Key。

API Key 默认空白；切换平台或修改地址会清空输入框中的旧 Key，不会把密钥发错平台。只使用你选定的模型，不自动换平台或换成更贵的模型。连接测试仅发送测试文字，不发送私人记录；测试和整理的用量计入你自己的 API 账户。

预设不代表所有账号都能调用相同模型，也不代表免费。请以所选平台的模型权限、价格和额度为准。ChatGPT 等聊天会员与 API 额度不是一回事。

## 录音和隐私

人声筛选与 SenseVoice 中文转写在手机本地进行，转写成功并保存文字后自动删除对应录音；失败录音临时保留供重试。云端只接收需要处理的文字、偏好和相关记录，不上传原始录音。

仅记录有权记录的内容，并取得相关参与者同意。AI 可能误识别，重要金额、日期和责任归属请核对。请勿把密钥或私人会议内容贴到公开反馈中。
