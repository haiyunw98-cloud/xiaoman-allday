# 小满全天记

### 留下有用的信息，找回重要的事。

开完会，留下的不该只是一长段文字。小满全天记是一个正在持续打磨的 **安卓个人记录与记忆助手**，围绕时间轴、重点整理、候选待办、每日回顾和历史内容检索，把记录变成以后还能用得上的信息。

[了解使用方式](#从记录到找回) · [版本与下载](#版本与下载) · [提交反馈](https://github.com/haiyunw98-cloud/xiaoman-allday/issues/new/choose) · [隐私与边界](#隐私与使用边界)

> **当前阶段：个人使用验证后的外部体验准备。** 开发者已连续自用二十多天并做了多轮优化；这不代表已经完成不同设备、不同场景的全面验收。本仓库先提供产品介绍与反馈入口，尚未提供可公开分发的安装包。

## 从记录到找回

| 你关心的事 | 小满的产品流程 |
| --- | --- |
| 一段记录太长，回看费劲 | 按时间整理有用内容，形成可回看的时间轴 |
| 聊了很多，不知道重点在哪 | 提取重点，合并围绕同一件事的信息 |
| 别人说的任务不一定归我 | 提出候选待办，由使用者确认后再跟进 |
| 忙完一天，想知道推进了什么 | 根据已整理内容形成每日回顾，而不是简单堆转写 |
| 记得聊过，却找不到 | 通过搜索或向小满提问找回历史记录，并核对原有内容 |

这些是产品的核心使用方向，不是准确率或永不中断的承诺。不同版本的具体支持情况、限制与修复，以后续版本说明为准。

## 适合谁

- 会议较多、需要反复回顾讨论的人。
- 同时跟进多个项目、希望梳理重点与下一步的人。
- 想建立自己的记录习惯，而不是只积累录音文件的人。

不以秘密录音为卖点，不把所有听到的事情都当作你的任务，也不代替使用者做重要业务判断。

## 版本与下载

**目前没有在此仓库发布 APK。** 不用旧调试包冒充新发行版，也不会把私人测试数据打包给别人。

通过分发检查后的版本会放在 [Releases](https://github.com/haiyunw98-cloud/xiaoman-allday/releases)，并说明：

- 版本号、支持的系统及安装方法；
- 安装文件的校验值、升级注意事项；
- 本地与云端处理范围、使用费用或额度；
- 已知问题与反馈方式。

GitHub 项目公开 **不等于 App 源码已经开源**。本仓库目前是产品展示与反馈仓库，不包含 App 源码、模型密钥或用户记录。没有宣布免费无限云端、终身授权或已确定售价。

**GitHub Issue 默认公开。请使用代号，不填写电话、微信号、私人会议原文或身份证明。** 留下意向不代表已经获得安装包或购买资格；实际开放时会先说明版本、费用和使用边界。

## 隐私与使用边界

- 仅记录你有权记录的内容，并在适用场景取得参与者同意。
- 不用未获授权、涉密或高度敏感的会议做公开体验。
- 不宣称所有处理都在本地；若某个版本使用云端，应先了解服务商与上传范围。
- AI 转写与整理可能出错，金额、日期、人物归属和任务责任需要核对。
- 系统权限、后台限制和设备状态会影响持续记录；不承诺全天绝不漏录。
- 公开反馈前先脱敏，不上传 API Key、录音、数据库或带个人信息的截图。
