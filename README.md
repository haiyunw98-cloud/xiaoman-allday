# 小满全天记

**按关注领域提炼信息，建立可回顾、可检索的个人记录。**

小满全天记是一款面向 Android 的智能记录应用。用户主动开启录音后，应用在手机本地筛选人声并完成转写，再通过用户配置的 AI 服务，按关注领域提取有用信息，形成时间轴、主题重点、候选待办和每日 AI 日记。

**它不止提供语音转写，更关注信息的筛选、归纳与后续查找。** 你可以设置希望保留的内容，在需要时搜索历史记录，或直接向小满提问。

## 核心能力

| 能力 | 功能说明 |
| --- | --- |
| 关注领域筛选 | 根据用户设置的身份背景与关注领域，从转写内容中提炼相关信息，减少无信息量的闲聊和重复内容。 |
| 时间轴记录 | 按时间组织整理结果，最新内容优先显示，支持按日期浏览、按时段展开与折叠。 |
| 主题重点归纳 | 围绕同一主题合并多个片段，整理背景、进展、结论与后续关注事项。 |
| 待办建议与确认 | 从整理内容中识别候选事项，由用户确认后加入待办，支持提醒与后续管理。 |
| AI 日记与日历 | 根据当天已整理的信息生成日记；授权系统日历且存在可写日历时，自动写入当天日程。 |
| 历史检索与问答 | 搜索人物、事情、项目或日期，也可直接提问，从已有记录中查找信息并查看相关来源。 |

日记默认于每天 **21:00** 整理，依据已有整理结果生成，而不是简单拼接原始转写。日记风格、篇幅、关注领域、待办提醒及定时停止录音均可在设置中调整。系统休眠、网络或任务积压可能导致生成时间延后。

## 从记录到回顾

**主动开启记录 → 本地人声筛选与转写 → 按关注领域提炼 → 时间轴与主题重点 → 待办确认、每日回顾与历史问答**

例如，你可以将关注领域设置为项目进展、学习笔记或创意灵感。应用会依据这些偏好整理后续记录；重点内容自动保留，候选待办则等待你确认。以上为使用方向示例，并非预置记录或识别效果承诺。

## 安装与配置

1. **下载安装。** [直接下载 APK](https://github.com/haiyunw98-cloud/xiaoman-allday/releases/download/v0.1.2-public/xiaoman-allday-0.1.2-public.apk)，在 Android 13 及以上的 ARM64 手机上安装。安装包约 272 MB，已包含中文转写模型，建议预留至少 1 GB 空间。
2. **设置关注领域。** 打开右上角齿轮，在「关注重点与使用习惯」中填写关注内容；身份背景可留空。首次安装不预置个人记录或身份资料。
3. **配置 AI 服务。** 在「云端 API」选择服务平台，填写自己的 API Key，确认模型并测试连接后保存。
4. **开始记录。** 手动点击「开始」，按提示授予麦克风和通知权限。可随时暂停，也可设置每日自动停止时间；应用不会因此自动开启录音。
5. **按需授权日历。** 如需自动保存日记至日历，在设置中选择「AI 日记加入日历」并授权。

## AI 服务与使用费用

语音转写使用手机本地的 **SenseVoice**。重点提炼、日记生成及相关 AI 问答使用用户配置的云端服务，无需在手机上另行安装大语言模型。

内置阿里云百炼、DeepSeek、硅基流动和 OpenAI 平台预设，支持调整模型；其他服务可通过自定义 **OpenAI 兼容 Chat Completions 接口**配置 HTTPS 地址、模型与 Key。

API Key 默认留空，云端用量由所选平台按用户账户计费，连接测试也会产生少量用量。平台预设不代表免费额度或调用权限保证。应用使用用户选定的服务与模型，不自动切换至其他平台或更高价模型。

## 数据处理与隐私

- **本地处理音频：** 人声筛选与语音转写在手机上完成，原始录音不上传至云端整理服务。
- **按需处理文字：** 云端接收待整理文字、使用偏好及相关记录，用于信息提炼与问答；本产品并非完全离线应用。
- **录音保留策略：** 转写成功并保存文字后删除对应录音；失败录音临时保留以便重试。
- **用户控制采集：** 录音需主动开启，使用者应确认记录权限、取得参与者同意，并遵守所在场所及组织的要求。

AI 可能出现识别、归纳或责任归属错误，重要金额、日期与事项需人工核对。后台记录与处理受设备、系统设置、电量和网络影响，不承诺任何环境下持续不中断。
